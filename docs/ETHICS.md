# Ethics and data handling

Only capture traffic generated by the collection machine and only with permission for the access network. Do not collect other users' traffic, credentials, resolver profile identifiers, or raw public IP addresses.

The manifest `public_ip` field is never populated with a literal address by the capture driver. If an operator supplies `--public-ip`, the driver stores only a salted, truncated hash. Legacy manifest migration also replaces any literal address found in that column with a salted hash before the migrated file can receive new rows. If no lookup succeeds, the field is blank; a network label may be recorded separately in `network`, but a raw address is never retained.

The salt is read from `ENCDNS_IP_SALT` on the collection machine and is never committed. Any manifest, backup, report, or other artifact intended for commit must contain only a network label, a salted hash, or an empty public-IP value—never a raw IP address.

PCAPs, live manifests, smoke manifests, and pre-migration backups remain local-only. The archived pilot manifest is the sole committed raw-manifest record.
